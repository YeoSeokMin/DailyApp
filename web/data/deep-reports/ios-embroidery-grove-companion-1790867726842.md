- **해결**: 프로젝트별로 재료 목록(실 색상·수량), 도안 첨부, 진행 상태를 하나의 앱에서 통합 관리한다. [확인]
- **차별점**: 자수라는 단일 공예에 완전히 특화된 UX — 일반 프로젝트 관리 앱에서는 제공하지 않는 자수 전용 필드(색상 코드, 바늘 규격 등)를 기본 지원한다. [추론]

## 핵심 인사이트

### 개발자를 위한 교훈
1. **"자기 자신이 첫 번째 유저"의 힘**: 직접 겪은 페인포인트를 해결하면 타겟 유저의 공감을 즉각적으로 얻고, 제품-시장 적합성(PMF) 검증 비용이 거의 없다. [추론]
2. **니치의 깊이가 진입 장벽**: "자수 전용"이라는 좁은 정의가 오히려 일반 앱과의 경쟁을 피하게 한다. 폭넓게 만들수록 경쟁이 늘어나는 역설을 이해할 것. [추론]
3. **커뮤니티가 마케팅 채널**: Reddit r/Embroidery, Instagram 자수 계정, Pinterest 보드가 가장 효과적인 무료 마케팅 채널이다. 앱스토어 ASO보다 커뮤니티 진입이 우선이다. [추론]
4. **데이터베이스 내장이 킬러 기능**: DMC/Anchor 실 색상 전체 데이터베이스를 내장하면 검색·자동완성이 가능해지고, 이 기능 하나로 경쟁 앱과 명확한 격차가 생긴다. [추론]
5. **포트폴리오 전략**: 동일 코드베이스를 뜨개질·퀼팅 등 인접 공예로 확장하면 개발 비용 없이 시장을 여러 개 커버할 수 있다. [추론]

### 개선 제안
1. **DMC/Anchor 실 데이터베이스 내장** — 색상 코드 입력 시 색상명·RGB값 자동 완성 — 실현성: **높음** [추론]
2. **진행 상태 사진 타임라인** — 프로젝트별 작업 사진을 날짜순으로 정렬해 포트폴리오 뷰 제공 — 실현성: **높음** [추론]
3. **재료 쇼핑 리스트 내보내기** — 부족한 실 색상·수량을 메모/카카오톡으로 공유 — 실현성: **높음** [추론]
4. **완성작 SNS 공유 카드** — 브랜딩된 완성 인증 이미지 자동 생성 (바이럴 유도) — 실현성: **중간** [추론]
5. **iCloud 동기화** — 아이폰↔아이패드 데이터 공유 (아이패드로 도안 보며 아이폰으로 진행 기록) — 실현성: **높음** [추론]

### 스핀오프 앱 아이디어
1. **Knitting Grove**: 동일 구조의 뜨개질 전용 앱 — 실 중량/색상/바늘 게이지 관리 특화 [추론]
2. **Quilting Grove**: 퀼팅 전용 앱 — 패브릭 색상 조합, 패턴 블록 단위 진행 관리 [추론]
3. **Craft Stash Manager**: 재료 관리에 특화한 범용 공예 재고 앱 — 사진 촬영으로 재고 DB 구축 [추측]
